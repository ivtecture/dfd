# DFD — Диаграмма потоков данных (система видеоконференций)

## Диаграмма

```mermaid
flowchart TB
    %% Внешние сущности
    U["Участники"]
    O["Организаторы"]

    %% Процессы
    P1(["Идентификация"])
    P2(["Создание сессии"])
    P3(["Управление участниками"])
    P4(["Вход в сессию"])
    P5(["Передача аудио/видео сообщения"])
    P6(["Сервис сохранение сессий"])

    %% Хранилища данных
    D1[("База пользователей")]
    D2[("База сессий")]
    D3[("База записи конфиренций")]

    %% Потоки данных
    U -->|"Имя"| P1
    P1 -->|"Статус входа"| U
    O -->|"Имя"| P1
    P1 -->|"Статус входа"| O
    P1 -->|"Имя"| D1
    D1 -->|"Подвердить"| P1
    P1 -->|"Имя участника"| P4

    O -->|"Запрос на создание сессии"| P2
    P2 -->|"Запрос на управление"| P3
    P3 -->|"Данные об участниках"| P2
    P2 -->|"Список участников, Данные о сессии"| D2
    P3 -->|"Данные участников"| D2
    D2 -->|"Данные о сессии"| P3

    D2 -->|"Код сессии"| P4
    P4 -->|"Данные об участниках"| D2
    D2 --> O

    O -->|"Начало сессии"| P5
    D2 -->|"Данные о сессии"| P5
    P5 -->|"Получение сообщений"| U
    P5 -->|"Получение сообщений"| O
    P5 -->|"Данные собщений"| P6
    P6 -->|"Сохранение"| D3
    D3 -->|"Готовое сохранение"| P6
```

## Элементы диаграммы

| Тип              | Название                       |
| ---------------- | ------------------------------ |
| Внешняя сущность | Участники                      |
| Внешняя сущность | Организаторы                   |
| Процесс          | Идентификация                  |
| Процесс          | Создание сессии                |
| Процесс          | Управление участниками         |
| Процесс          | Вход в сессию                  |
| Процесс          | Передача аудио/видео сообщения |
| Процесс          | Сервис сохранение сессий       |
| Хранилище данных | База пользователей             |
| Хранилище данных | База сессий                    |
| Хранилище данных | База записи конфиренций        |
